# EviSelect Project Page

Static project page for:

**EviSelect: Evidence-Driven Dynamic Visual Selector for Efficient Long Video Understanding**

## Local Preview

From this folder, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deployment

Upload the contents of this folder to a GitHub repository and enable GitHub
Pages for the branch that contains `index.html`.

## Files

- `index.html` - static project page
- `styles.css` - page styling
- `assets/teaser.png` - comparison teaser
- `assets/method-overview.png` - method overview figure
- `assets/qualitative-results.png` - qualitative comparison
